# マウス周辺の画質優先（実験機能）

## 動作

表示倍率と配信解像度を保ったまま、ホストのマウス周辺は元のサンプリングを維持し、背景を粗くします。動画圧縮前の画像処理です。NVENCのAQや領域別QP指定とは別の機能で、GPUごとのROI対応に依存せず通常の動画として送ります。Moonlightと共通通信ライブラリの変更は不要です。

鮮明な円の外側に、半径の25%幅の滑らかな移行帯を設けます。背景は出力画素に固定したセル内の4点を線形サンプルし、その平均を使います。厳密な全画素平均ではありません。マウスの移動で配信画像の配置や入力座標を変更しません。

WindowsのD3D11色変換を使うハードウェアエンコード（NVENC、D3D11-backed AMF/Quick Sync）が対象です。SDR/HDR、4:2:0/4:4:4で同じ画像処理を使います。ソフトウェア/RAM変換は未対応で、警告を記録して通常画像を送ります。他OSのSunshineホストは未対応です。

物理デスクトップ座標を使用します。負のモニター座標、90/180/270度の回転、配信画像の余白に対応します。OSがマウス位置を返せない場合や、マウスが配信対象外のモニターにある場合は、そのフレーム全体を通常画質に戻します。

## 設定

Sunshine CustomのWeb UI → Configuration → Audio/VideoのWindows向け設定：

- Preserve Detail near the Cursor (Experimental)：既定OFF。
- Sharp Area Radius：32〜1024、既定160。配信画像の表示部分における画素単位。
- Background Cell Size：2〜16、既定4。大きいほど背景の細部を減らします。

変更を保存してSunshineを再起動します。設定ファイルの例：

```ini
cursor_focus = enabled
cursor_focus_radius = 96
cursor_focus_background_scale = 4
```

設定をOFFにすると元のサンプリングに戻ります。ホストの画面を変更する機能ではなく、送信する画像だけを加工します。

## 1Mbps回線の試験候補

Moonlight側で1280×720、10fps、500kbps、4:2:0、HDRなしを指定します。両側でハードウェア対応するHEVCまたはAV1を使用し、まず音声なしで確認します。540pで接続安定性を先に確認してから720pへ上げる方法もあります。

画面全体を720pへ縮小した場合、この機能は720pの元画像を超える細部を復元できません。より小さな文字を読ませたい場合は配信解像度を上げる必要があります。背景を粗くすることで、低いビットレートの画質予算を操作箇所へ回しやすくするのが目的です。

ビットレートが同じなら転送量が必ず減るものではありません。マウスが動くと鮮明な領域も動くため、かえってフレーム間の変更量が増える場面もあります。FEC、音声、ヘッダーを含めた実測が必要です。接続可否と実回線での可読性は未検証です。

## 比較方法

同一の文字サイズ、解像度、FPS、コーデック、ビットレート、音声、FECで比較します。各条件で静止60秒、同じ文章のスクロール60秒、同じマウス移動60秒を測ります。

計測対象は当該配信のネットワーク通信です。PC全体の通信量をそのままSunshineの実測値とは扱いません。帯域と損失を制限した環境でも同じ条件を繰り返します。

## 自動検証と境界

- 座標・回転・余白・不正値・マウス位置不明・モニター外・設定上限をgtestで検証します。
- 実際のHLSLをD3D11 WARPで描画し、OFFの画素一致、鮮明部の画素一致、背景の粗さ、境界の移行、マウス追従を確認します。
- 全色変換シェーダーをコンパイルし、SDR/HDR・色形式ごとの組み込みを確認します。
- 設定保存とWindows限定のUI表示を検証します。
- 実GPUのエンコーダを通した別端末配信、1Mbps回線での遅延と総転送量は別途実測します。

## 試用パッケージ

試用版を展開し、Start Sunshine.cmdで起動します。共通設定ランチャーは管理ログインとMoonlightのペアリングをビルド間で引き継ぎます。詳細は[設定共有](shared-config.md)を参照してください。インストール版が同じポートで稼働している場合は、既存の接続を終えてそのサービスを停止してから起動してください。この作業ではインストール版のサービスや設定は変更していません。

## 矩形と背景の更新周期

Web UIのAudio/VideoでFocus Area ShapeをRectangleにし、Sharp Rectangle Width × Heightを指定します。各辺32〜8192、既定512×320。配信画像の余白を除いた画素単位で、表示倍率・入力座標を変えずにマウスへ追従します。円形の既存設定も利用できます。矩形の外には、短い辺の半分の25%幅の移行帯があります。

Background Updatesで次を選べます。

- Every frame：背景も毎フレーム更新。既存設定の既定動作。
- Update small areas in sequence：背景を6列×5行の30区画に分け、Background Refresh Cycle (seconds)で指定した時間を目標に順番に更新。
- Stop background updates：背景の自動更新を停止。マウス周辺は最新のままで、通った場所の最新内容を保持します。離れた部分には背景セルサイズの粗さが適用されます。

ループ周期は0.001〜60秒で指定できます。初回の背景だけは全体を初期化します。以降、1フレームの背景更新は最大8区画です。極端に短い周期や低FPSでは、実際の一巡は指定より長くなります。長い停止から復帰しても、未実行の更新をまとめて全画面へ適用しません。

マウスが動いた際には、直前の優先領域も最新画像で更新してから保持し、キャプチャ画像に合成された旧カーソルの残像を抑えます。背景を停止していても、通った場所が最初の古い画像へ戻ることはありません。未知のマウス位置・配信モニター外では既存どおり通常画像へ戻り、次の有効な位置で背景を初期化します。キャプチャサイズ・色形式変更や再接続も背景を初期化します。

設定ファイルではcursor_focus_shape = rectangle、cursor_focus_widthとcursor_focus_heightに幅・高さ、cursor_focus_background_loop_msに一巡のミリ秒数を指定します。1000なら1秒、0なら毎フレーム、-1なら停止です。

この機能はGPU上に背景を保持する画像処理です。ブロック別QP指定、黒塗りつぶし、回線速度に合わせるネットワーク送信間隔制御は今回の変更に含まれません。パーティクルの背景が静止・低頻度になるので画質予算を操作箇所へ回しやすくなりますが、音声・FEC・パケットの余白は残り、転送量の上限を保証しません。

Sunshineを保存・再起動してから接続してください。現在の接続を自動的に再起動する操作は行いません。パスワードとペアリングを維持するには共通設定ランチャーで起動してください。
